# 🚀 Restaurar Dados do Supabase

## Passo a Passo Simples:

### 1. Abra o Terminal (Prompt de Comando)

Pressione `Win + R`, digite `cmd` e pressione Enter

### 2. Navegue até a pasta do projeto

Cole este comando e pressione Enter:

```bash
cd "C:\Users\ferdi\APLICATIVO FALTAS\ceti-auristela-soares---professor-app"
```

### 3. Execute o script de restauração

Cole este comando e pressione Enter:

```bash
node restaurar_dados.js
```

### 4. Aguarde a conclusão

Você verá mensagens como:
- 🗑️ Limpando dados antigos...
- ✅ Dados antigos removidos
- 👨‍🏫 Inserindo professores...
- ✅ 20 professores inseridos
- 📚 Inserindo disciplinas...
- ✅ 6 disciplinas inseridas
- 👥 Inserindo alunos...
- ✅ 6 alunos inseridos
- 🎉 RESTAURAÇÃO CONCLUÍDA COM SUCESSO!

---

## ✅ Pronto!

Depois que aparecer "RESTAURAÇÃO CONCLUÍDA", seus dados estão no Supabase!

Agora pode testar o app localmente:

```bash
npm run dev
```

E abrir: http://localhost:5173
